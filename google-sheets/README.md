# Google Таблицы + Heli: функция `=ASK()`

Пример [Google Apps Script](https://developers.google.com/apps-script), который вызывает OpenAI-совместимый API [Heli](https://getheli.ru) прямо из ячейки таблицы.

## Что делает `ASK`

| Формула | Поведение |
|---------|-----------|
| `=ASK("Кратко объясни VLOOKUP")` | Запрос к модели `openai/gpt-4.1-mini` |
| `=ASK(A1; "anthropic/claude-sonnet-4.6")` | Тот же запрос, но с указанной моделью |

Функция отправляет `POST https://getheli.ru/v1/chat/completions` с телом в формате OpenAI Chat Completions и возвращает **только текст** из `choices[0].message.content` (без JSON и без служебных полей).

Другие слаги моделей — в [каталоге Heli](https://getheli.ru/models).

## Установка

1. Откройте Google Таблицу → **Расширения** → **Apps Script**.
2. Удалите содержимое файла `Code.gs` по умолчанию и вставьте код из [`Code.gs`](Code.gs) этого репозитория (или скопируйте файл целиком).
3. Сохраните проект (Ctrl+S / Cmd+S).
4. **Проект** (иконка шестерёнки) → **Настройки проекта** → вкладка **Свойства скрипта** → **Добавить свойство скрипта**:
   - **Свойство:** `HELI_API_KEY`
   - **Значение:** ваш ключ `sk-heli-...` из [кабинета Heli](https://getheli.ru)
5. При первом запуске Apps Script может запросить разрешение на **внешние запросы** (`UrlFetchApp`) — подтвердите для своего аккаунта.
6. Вернитесь в таблицу и введите формулу, например:

```text
=ASK("Переведи на английский: Доброе утро")
```

или с текстом из ячейки `A2`:

```text
=ASK(A2)
```

С моделью (в русской локали Google Sheets аргументы часто разделяют `;`):

```text
=ASK("Суммируй в три пункта"; "openai/gpt-4.1-mini")
```

После изменения кода в редакторе иногда нужно обновить ячейку (F2 → Enter) или пересчитать лист.

## Ключ API и безопасность

- **Не вставляйте** `sk-heli-...` в ячейки, комментарии к ячейкам или в исходный код `Code.gs`.
- Храните ключ **только** в свойствах скрипта (`HELI_API_KEY`).
- Таблицу с формулой `ASK` не публикуйте в открытый доступ: любой, кто может редактировать скрипт или свойства, получит доступ к ключу.
- При утечке ключа отзовите его в кабинете Heli и создайте новый.

## Ответ и ошибки

- **Успех:** в ячейке появляется строка с ответом модели.
- **401:** неверный или отозванный ключ — проверьте `HELI_API_KEY`.
- **402:** нулевой баланс — пополните баланс в кабинете Heli.
- **Другие коды:** функция вернёт текст вида `Heli HTTP <код>: <сообщение>`.

Лимиты Google на время выполнения пользовательских функций и квоты `UrlFetchApp` действуют как обычно; длинные запросы могут не уложиться в лимит.
